## 摘要

**（需要从 arXiv 补充完整信息）**

HLTM 提出了一种层次化记忆架构，专为 LinkedIn 招聘 Agent 设计，在候选人匹配和长期客户关系维护场景中管理异构记忆类型。

## 核心贡献

1. **领域定制的层次化记忆**：针对招聘场景的专门记忆设计
2. **多类型记忆管理**：同时管理候选人信息、职位需求、交互历史等异构数据
3. **关系导向的记忆组织**：以人与人、人与职位的语义关系为核心

## 为什么重要

招聘 Agent 需要同时维护多个候选人和职位的复杂关系，现有通用记忆系统难以捕捉这种领域特定的结构。HLTM 提供了领域定制记忆系统的参考设计。

## 与端侧/移动端的相关性

招聘 Agent 通常在 CRM 系统中运行，HLTM 的层次化设计对需要管理多个实体及其关系的端侧应用有参考价值。
