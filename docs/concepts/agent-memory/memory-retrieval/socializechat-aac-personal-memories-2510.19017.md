# SocializeChat: A GPT-Based AAC Tool Grounded in Personal Memories to Support Social Communication

**作者:** Wei Xiang, Yunkai Xu, Yuyang Fang, Zhuyu Teng
**发表:** 2025-10-21

## 摘要

患有言语障碍的老年人在参与有意义的社交沟通时面临挑战，尤其是使用主要满足基本需求的辅助替代通信（AAC）工具时。此外，有效的聊天往往依赖个人记忆，而这是难以提取和重用的。本文介绍 SocializeChat，一种基于 GPT 的 AAC 工具，通过个人记忆生成句子建议，使有言语障碍的老年人能够进行更自然的社交对话。

## 核心貢獻

1. **个人记忆增强的 AAC**: 将个人记忆系统嵌入 AAC 工具，生成更自然、更有个人风格的句子建议
2. **记忆提取与重用**: 从用户历史数据中提取个人记忆，转化为可用的聊天内容
3. **社交沟通支持**: 超越基本需求表达，支持更深层次的社交互动
4. **GPT 驱动生成**: 利用 GPT 的生成能力，将记忆转化为符合上下文的自然语言

## 為什麼重要

AAC 工具传统上只支持基本需求的表达，而社交记忆的加入使这些工具能够支持更高质量的社会互动。对于老年人和有言语障碍的群体，个人记忆驱动的交流工具是社会参与的重要保障。

## 與端側/移動端相關性

1. **移动端原生 AAC**: 手机和平板是 AAC 工具的主要载体
2. **隐私优先**: 个人记忆必须在本地处理，不适合云端共享
3. **实时生成**: 端侧实时生成句子建议，无网络延迟
4. **可穿戴扩展**: 可与智能手表配合，在各种场景下提供 AAC 支持
