## 摘要

在扩展时间范围内运行的 AI Agent 积累了服务于多个并发目标的经验，且常常需要对同一事件维持相互冲突的解读。例如，客户谈判中的让步对某一战略目标编码为"建立信任投资"，对另一目标则编码为"合同责任"。当前记忆架构假设单一正确编码，或仅支持统一存储上的多视图。本文提出 Rashomon Memory：一种并行目标条件 Agent 根据各自优先级对经验进行编码，并在查询时通过论证进行协商的架构。每个视角维持自己的本体和知识图谱。检索时，各视角提出解读、基于非对称领域知识相互批评提议，并使用 Dung 的论证语义确定哪些提议存活。生成的攻击图本身即是一种解释：它记录了哪个解读被选中、考虑了哪些替代方案以及基于什么理由被拒绝。本文展示了一个概念验证，表明检索模式（选择、组合、冲突呈现）从攻击图拓扑中涌现，且冲突呈现模式（系统报告真实分歧而非强制解决）让决策者直接看到底层解读冲突。

## 核心贡献

1. **多视角记忆架构**：每个目标/视角维持独立的本体和知识图谱，避免强制统一
2. **论证驱动的协商检索**：通过 Dung 的形式化论证语义解决多视角冲突
3. **攻击图即解释**：检索结果自带完整的决策理由，支持可解释 AI
4. **冲突呈现模式**：不强制解决分歧，而是呈现给用户自己判断——适合高风险决策场景

## 为什么重要

真实世界的 Agent 需要同时追求多个可能冲突的目标（既要提高用户满意度、又要控制成本、又要遵守隐私规则），而现有记忆系统将所有经验编码为单一版本，丢失了多目标视角的丰富性。Rashomon Memory 提出了一个优雅的解决方案：在检索时通过论证协商而非预先强制统一来呈现多视角记忆。对 Agent 系统而言，这意味着记忆不只能是"查找表"，而是可以进行"推理"的动态知识结构。

### 与移动端/端侧的相关性

- **知识图谱**是端侧推理的常用表示形式
- **论证语义**可解释性高，适合需要向用户解释决策理由的移动端应用
- 适合**隐私敏感**场景：不同视角的知识图谱可设置不同的访问权限
