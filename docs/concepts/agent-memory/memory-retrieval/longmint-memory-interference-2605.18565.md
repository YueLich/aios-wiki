## 摘要

真实世界的智能体在长期运行中面临信息的持续更新和跨记忆干扰，需要准确回忆和聚合推理多条信息。然而现有基准测试关注的是静态、独立的信息召回，无法评估智能体在信息干扰下的记忆准确性。LongMINT 提出一种新的评估基准，系统性地测试智能体在多目标干扰、长程信息更新条件下的记忆性能。

## 核心贡献

1. **多目标干扰评估范式**：设计信息重复更新、相互干扰的场景，测试记忆系统的区分和检索能力
2. **聚合推理能力评估**：不仅测试单条记忆召回，还测试多条相关记忆的聚合推理
3. **动态环境基准**：模拟真实世界信息的持续更新，而非静态问答
4. **多维度评估指标**：提出记忆准确性、干扰抗性、聚合推理等综合评估维度

## 为什么重要

现有的 Agent 记忆基准（如 MemoryBench）主要测试静态、独立信息的召回，无法反映真实场景中信息的重叠、冲突和更新特性。LongMINT 填补了这一空白，揭示了当前记忆系统在复杂信息环境中的真实能力瓶颈，对后续记忆系统设计有重要指导意义。

## 与端侧/移动端的相关性

端侧 Agent 面临的一个关键挑战是：设备上的记忆会随着使用不断积累、覆盖、更新，与云端记忆管理有本质区别。LongMINT 的多目标干扰场景正是端侧记忆系统需要解决的核心问题——如何在资源受限的环境下维护一个准确、抗干扰的长期记忆。该基准为端侧记忆系统提供了重要的评估标准。
