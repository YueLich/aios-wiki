## 摘要

虽然 LLM Agent 可以利用工具完成复杂任务，但仍需要记忆来维持跨轮一致性并在长程交互中积累可重用信息。然而，基于检索的外部记忆系统在线开销低但因查询构建和候选过滤能力有限而导致准确率不稳定；反之，许多系统使用重复的大模型调用进行在线记忆操作来提高准确率，但会在长程交互中累积延迟。本文提出 LightMem，一种由小型语言模型（SLM）驱动的轻量级 Agent 记忆系统。LightMem 将记忆检索、写入和长期整合模块化，并分离在线处理与离线整合，以在有限计算下实现高效记忆调用。LightMem 将记忆组织为短期记忆（STM，用于即时对话上下文）、中期记忆（MTM，用于可重用的交互摘要）和长期记忆（LTM，用于整合知识），并使用用户标识符支持多用户环境下的独立检索和增量维护。在线上，LightMem 在固定检索预算下运行，通过两阶段程序选择记忆：基于向量的粗召回后接语义一致性重排序。离线上，它抽象可重用交互证据并增量整合到 LTM。实验表明 LightMem 在各模型规模上均持续提升，在 LoCoMo 上平均 F1 提升约 2.5（对比 A-MEM），同时效率更高、中位延迟更低（检索 83ms、端到端 581ms）。

## 核心贡献

1. **SLM 驱动的轻量记忆**：用小型语言模型替代大模型执行记忆操作，大幅降低延迟
2. **三层记忆架构**：STM（短期）→ MTM（中期）→ LTM（长期），支持增量维护
3. **两阶段检索**：向量粗召回 + 语义一致性重排序，平衡精度与效率
4. **多用户支持**：通过用户 ID 实现独立检索与增量维护
5. **超低延迟**：检索 83ms、端到端 581ms，在消费级硬件上可运行

## 为什么重要

端侧 Agent 的核心约束是计算资源有限。LightMem 证明了用 SLM 替代大模型进行记忆操作是可行的——在保持准确率的同时将延迟降低一个数量级。这对手机、手表等移动端 Agent 至关重要。

### 与移动端/端侧的相关性

- **SLM 可在设备本地运行**，无需云端调用，保护隐私
- **三层记忆架构**天然适配移动端分层存储（内存 → SSD/Flash）
- **超低延迟**（83ms 检索）满足实时交互需求
- **多用户场景**支持手表、共享平板等设备
