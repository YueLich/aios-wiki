## 摘要

现有的大型语言模型智能体基准测试主要评估推理、规划和执行能力，而记忆作为智能体在时间维度上存储、更新和检索信息的关键能力，却鲜有系统性的评估。EvoMemBench 从自进化视角提出一种新的 Agent 记忆评估范式，测试记忆系统如何在动态环境中持续适应、积累和泛化知识。

## 核心贡献

1. **自进化评估范式**：设计需要智能体在持续变化的任务中维护和更新记忆的场景
2. **记忆动态性测试**：不仅评估静态记忆的存储和检索，还评估记忆的更新、覆盖和遗忘机制
3. **知识迁移能力评估**：测试旧任务学到的记忆如何迁移到新任务
4. **多领域覆盖**：涵盖对话、推理、具身等多种 Agent 应用场景

## 为什么重要

自进化是智能体真正实现终身学习的关键标志——能够从经验中持续构建和更新知识。EvoMemBench 首次系统性地评估了这一能力，填补了 Agent 评估体系中记忆维度的空白。该基准的提出将推动记忆系统从"静态知识库"向"动态自进化记忆"演进。

## 与端侧/移动端的相关性

端侧 Agent 的核心竞争力在于能够在设备本地持续学习和适应用户习惯，无需云端同步。EvoMemBench 的自进化视角与端侧持续学习的需求高度契合——设备上的记忆需要随时间自进化，同时保持对用户隐私的保护。该基准为端侧记忆系统提供了明确的设计目标：不仅要存储，更要持续进化。
