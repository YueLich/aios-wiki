## 摘要

现有的 GUI 智能体在长期任务中表现脆弱，原因在于缺乏跨大量界面转换的任务状态维护能力。MementoGUI 提出一种多模态记忆控制系统，将视觉、语言和交互状态统一建模，支持 GUI 智能体在多步骤任务中准确回忆和推理历史界面状态，显著提升长程任务成功率。

## 核心贡献

1. **多模态记忆控制架构**：将 GUI 界面截图、操作历史、任务上下文统一编码进记忆系统，支持视觉-语言-动作的跨模态检索
2. **GUI 特化记忆索引机制**：针对 GUI 界面层级结构设计的记忆组织方式，能够快速定位相关历史状态
3. **长期任务状态维护**：解决 GUI 智能体在 10+ 步骤任务中的状态遗忘问题
4. **多模态奖励信号**：利用视觉和语言双通道信号指导记忆的强化学习更新

## 为什么重要

GUI 自动化是 Agent 的重要应用场景，但现有方法（纯文本历史重放或单模态记忆）难以处理复杂的界面视觉状态。MementoGUI 首次系统性地将多模态记忆引入 GUI Agent，解决了视觉-语言-动作的跨模态记忆存储与检索难题，为长程桌面/移动自动化开辟了新方向。

## 与端侧/移动端的相关性

GUI Agent 是端侧智能的核心应用之一（手机操控、桌面自动化）。MementoGUI 的多模态记忆架构意味着可以在本地设备上维护一个压缩的多模态状态记忆，在保护用户隐私的同时实现个性化（设备特定）的 GUI 自动化。论文方法对移动端和桌面端部署均有直接参考价值。
