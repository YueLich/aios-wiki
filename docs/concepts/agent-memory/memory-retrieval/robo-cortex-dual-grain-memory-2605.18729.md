## 摘要

现实世界的具身智能体需要在未见过的环境中导航和交互，但现有的轨迹驱动或反应式策略难以从过去的经验中合成可泛化的策略——论文称之为"经验性遗忘症"（experiential amnesia）。Robo-Cortex 提出一种双粒度认知记忆系统，融合粗粒度语义知识与细粒度情景经验，使智能体能够在执行中自主构建、组织和检索记忆，实现终身学习。

## 核心贡献

1. **双粒度记忆架构**：将语义记忆（可泛化的知识）与情景记忆（具体经验轨迹）分离又融合，支持不同粒度的知识迁移
2. **自主知识归纳模块**：从交互经验中自动提取可复用的知识模式，无需人工定义
3. **经验性遗忘症的系统性解决**：通过记忆合成使智能体能够在新环境中复用历史经验
4. **自进化机制**：智能体能够主动识别知识缺口并通过探索来填补

## 为什么重要

具身智能的核心挑战之一是如何让智能体像人类一样"记住经验、泛化到新任务"。大多数现有方法要么依赖预训练知识（缺乏适应性），要么依赖短期轨迹（缺乏泛化能力）。Robo-Cortex 通过双粒度记忆为这一难题提供了新的解决思路——语义层提供可泛化的先验，情景层提供具体的执行经验，两者协同实现真正的终身学习。

## 与端侧/移动端的相关性

该工作对端侧部署有重要参考价值：双粒度架构允许将粗粒度语义知识缓存在本地知识库中，而细粒度情景记忆可以按需压缩存储。论文的自进化特性意味着智能体能够在设备上持续适应环境而无需云端更新，这对边缘计算和自主导航设备尤其有意义。
