## 摘要（翻译）

尽管自回归大型视觉-语言模型（LVLM）在多模态任务中表现出色，但它们面临**视觉信号稀释（Visual Signal Dilution）**现象：文本历史的积累扩大了注意力分配函数，导致视觉注意力随生成序列长度增加而衰减。

本文提出 **Persistent Visual Memory (PVM)**，一个轻量级可学习模块，确保持续、按需的视觉感知。PVM 作为与 LVLM 前馈网络（FFN）并行的分支集成，建立了一条**距离无关的检索路径**，直接为精确视觉感知提供视觉嵌入，从结构上缓解了深度生成中固有的信号抑制。

在 Qwen3-VL 模型上的广泛实验表明，PVM 以可忽略的参数开销带来显著改善，在 4B 和 8B 规模上都实现了一致的平均准确率提升，特别是在需要持续视觉感知的复杂推理任务中。此外，深入分析表明 PVM 能够抵抗长度诱发的信号衰减并加速内部预测收敛。

## 核心贡献

1. **发现视觉信号稀释现象**：揭示了 LVLM 在生成长文本时视觉注意力衰减的机制
2. **PVM 模块**：通过与 FFN 并行的轻量级分支，提供距离无关的视觉检索路径
3. **对量化和长度外推的鲁棒性**：PVM 的视觉感知不随文本长度增加而衰减

## 为什么重要

这是首个明确识别并系统性解决 LVLM 视觉注意力随生成长度衰减问题的工作。核心洞察是：
- 文本生成越长，模型对早期视觉输入的关注越少
- 在 Agent 场景中，这意味着视觉记忆会被新生成的文本"挤出"
- 并行视觉记忆路径提供了一种不影响生成能力但保持视觉持续感知的方法

## 与移动端/端侧的相关性

移动端 LVLM 部署面临特殊挑战：
- 移动端 Agent 需要处理长对话/长文档
- 视觉输入（摄像头、截图、文档图像）在长对话中容易被稀释
- PVM 的轻量级设计（可忽略参数开销）对移动端资源约束友好
