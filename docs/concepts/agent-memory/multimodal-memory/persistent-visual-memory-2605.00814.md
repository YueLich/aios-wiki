## 问题背景

自回归大型视觉-语言模型（LVLM）在多模态任务中表现出色，但面临**视觉信号稀释（Visual Signal Dilemma）**问题：随着文本历史的积累，注意力分配函数扩展，导致视觉注意力随生成序列长度增加而衰减。

---

## 核心贡献

本文提出 **Persistent Visual Memory (PVM)**，一个轻量级可学习模块：
- 作为 LVLMs 前馈网络（FFN）旁的并行分支
- 建立距离无关的检索路径，直接提供视觉嵌入
- 从结构上缓解深层生成中的视觉信号抑制

---

## 为什么重要

PVM 解决了 LVLMs 在复杂推理任务中的一个根本性限制：随着生成序列增长，视觉注意力退化。对于需要持续视觉感知的 Agent 场景（如视频理解、多轮交互、机器人感知），这一缺陷严重影响任务完成质量。

---

## 与端侧/移动端的相关性

端侧 LVLM（如手机端部署的 Qwen3-VL）对生成长度限制更敏感。PVM 通过轻量级额外模块以极小参数开销换取持续视觉感知，特别适合移动端资源受限场景。

---

## 核心方法细节

### 视觉信号稀释建模

分析注意力分配函数随文本历史增长的衰减规律，建立量化的信号稀释模型。

### 并行记忆分支

在 FFN 旁添加可学习的 PVM 模块，不破坏原有模型结构，通过距离无关路径直接检索视觉记忆。

### 对抗长度诱导衰减

即使在超长生成序列中也能维持视觉感知稳定性，加速内部预测收敛。

---

## 实验结果

在 Qwen3-VL（4B 和 8B）上验证，PVM 以可忽略的参数开销带来显著改进：
- 在复杂推理任务中精度持续提升
- 有效抵抗长度诱导的信号衰减
- 加速内部预测收敛
