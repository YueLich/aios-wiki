## 摘要（翻译）

可微分物理网络（differentiable physical networks）通过将可训练参数与物理平衡约束相结合，提供了一个研究学习的简洁环境。本文研究了在**可微分电阻网络**（由基尔霍夫定律 governing）的 sequential learning 和灾难性遗忘问题。

研究发现：虽然梯度调整可以学习单个输入-输出映射，但顺序学习多个冲突任务时会产生**灾难性遗忘**——新任务的学习会覆盖网络边 conductance 上的旧知识。具体地，团队对比了：
- **统一锚定（Uniform Anchoring）**：将所有参数均匀约束到历史值
- **归一化梯度加权锚定（NGWA）**：根据梯度相似性自适应调整约束强度

实验表明，两种方法均能减少遗忘（保留旧任务性能），但代价是增加新任务的最终损失——这是遗忘-适应 trade-off 的直接体现。

## 核心贡献

1. **首个在可微分电阻网络上研究灾难性遗忘的工作**，提供了透明、可解释的 CL 测试平台（每个参数对应物理元件，权重变化有明确意义）
2. **揭示物理约束本身就是正则化器**：网络拓扑和基尔霍夫定律作为归纳偏置，限制梯度传播路径，间接影响遗忘行为
3. **提出 NGWA 方法**：根据梯度方向相似性动态调整锚定强度，为参数级 CL 提供新思路
4. **定量化 trade-off**：明确测量了"保留旧任务"与"适应新任务"之间的精度权衡

## 为什么重要

可微分物理网络作为 CL 研究平台的意义在于：
- **透明性**：电阻值直接对应可解释的物理量，比神经网络黑箱更易分析遗忘发生的机制
- **可控性**：可以精确设计任务冲突程度，研究不同网络拓扑对遗忘的影响
- **跨学科启示**：为在硬件层面实现抗遗忘学习提供理论依据（如忆阻器网络）

## 与移动端/端侧的相关性

端侧持续学习的一个核心问题是**有限资源下的灾难性遗忘**。本文的可微分物理网络框架为：
- **理解遗忘机制**提供透明物理模型，而非依赖黑箱神经网络实验
- **硬件感知 CL 设计**：如果未来的端侧芯片使用模拟电路/忆阻器实现计算，理解物理约束对遗忘的影响至关重要
- **NGWA 的参数级自适应思想**可以迁移到端侧 LoRA/Adapter 类持续学习方法
