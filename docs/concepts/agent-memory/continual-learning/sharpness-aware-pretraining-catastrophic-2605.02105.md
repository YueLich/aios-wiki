## 摘要（翻译）

预训练优化器被调优以产生尽可能最强的基模型，基于一个假设：更强的起点在后续变化（如后训练和量化）后会产生更强的模型。但这忽略了**基模型的几何特性**——它控制着有多少基模型的能力在后续参数更新后能够存活。

本文研究了三种偏向更平坦极小值的预训练优化方法：
1. **Sharpness-Aware Minimization (SAM)**
2. **大学习率**
3. **缩短的学习率退火期**

在 20M 到 150M 参数的多种模型规模下，这些干预措施在五个常见数据集的后训练场景中一致改善了下游性能，**遗忘减少高达 80%**。

在规模上：在现有 OLMo-2-1B 检查点应用短期 SAM 中期训练后，MetaMath 后训练后遗忘减少 **31%**，4-bit 量化后减少 **40%**。

## 为什么重要

这是首个从**预训练阶段的几何特性**来解决持续学习/灾难性遗忘问题的工作。传统方法在微调阶段采取措施（如 EWC、正则化），而本文证明：**基模型进入的极小值类型**对后续任务适应后的遗忘程度有决定性影响。

## 关键数据

| 干预措施 | 遗忘减少 | 规模 |
|----------|----------|------|
| SAM 中期训练 | 31% (MetaMath) / 40% (量化) | OLMo-2-1B |
| 最高遗忘减少 | 80% | 20M-150M 参数 |

## 与移动端/端侧的相关性

移动端模型的持续适应面临严峻的遗忘问题：
- 移动端硬件限制要求频繁的量化/剪枝
- 个性化适应需要在有限数据上微调
- SAM 预训练的平坦极小值特性使模型对量化更鲁棒，直接减少移动端部署中的遗忘
