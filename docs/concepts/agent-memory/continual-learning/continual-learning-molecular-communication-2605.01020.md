- **方向**: 持续学习 · 分子通信 · 性能估算

## 摘要（翻译）

本文为**反馈型分子通信**（feedback-based molecular communication, MC）协议提出并评估了一种新的性能估算方法。分子通信是一种使用化学信号在纳米级设备间传递信息的仿生通信范式，其协议验证需要耗时耗力的湿实验或详细仿真。

本文关键洞察：将每次实验设置下的性能估算视为一个独立的"任务"，用持续学习（CL）算法来**增量式学习**一系列未曾经历过的估算任务——而非每次都从头训练。具体地，团队将弹性权重巩固（EWC）和记忆回放（Memory Replay）等经典 CL 方法适配到 MC 性能估算场景，展示了 CL 框架可以在新实验设置下**保留已学过的知识**，同时学习新的估算能力。

实验表明，CL 估算器在序列设置中显著优于非增量基线，且 EWC 在防止关键参数被覆盖方面表现突出。

## 核心贡献

1. **首个将 CL 框架应用于分子通信性能估算的工作**，将耗时仿真从"每次独立估算"转变为"增量累积知识"
2. **将 CL 方法（EWC + Memory Replay）适配到 MC 领域**，验证了 CL 在非标准学习任务（物理/化学仿真）中的泛化能力
3. **揭示了 MC 仿真加速的潜力**：通过 CL 增量学习，减少重复仿真次数，为纳米通信系统设计提供更快速的评估工具

## 为什么重要

分子通信是实现**体内纳米网络**（in-body nanonetworks）的关键技术，但每次协议验证都需要大量湿实验或精细仿真。本文展示了持续学习可以作为一种**数据/仿真效率工具**——让仿真系统"记住"已学过的配置，快速适应新配置。这对需要频繁调整参数的生物兼容通信系统设计有直接价值。

## 与移动端/端侧的相关性

虽然分子通信主要面向植入式纳米设备，但其背后的**增量性能估算**思路对端侧学习有启示：
- 端侧模型需要在新用户/新场景中快速适应而不遗忘旧知识
- 本文验证了 EWC 类方法在**非标准机器学习任务**（物理仿真）中的有效性，暗示了端侧持续学习的广阔空间
- 分子通信网络的分布式特性与边缘计算场景有相似之处——多个节点共享知识但资源受限
