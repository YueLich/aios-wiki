## 摘要

Implicit biases in both humans and large language models (LLMs) pose significant societal risks. Dual process theories propose that biases arise primarily from associative System 1 thinking, while deliberative System 2 thinking mitigates bias, but the cognitive mechanisms that give rise to this phenomenon remain poorly understood.

To better understand what underlies this duality in humans, and possibly in LLMs, we model System 1 and System 2 thinking as semantic memory networks with distinct structures, built from comparable datasets generated by both humans and LLMs. We then investigate how topological differences between these network structures give rise to different bias profiles.

The key finding is that System 1 semantic memory exhibits scale-free, highly clustered network topology conducive to fast associative activation of stereotypes, while System 2 memory exhibits more distributed, modular topology that enables deliberative correction. This structural duality is reflected in both human semantic memory (from word association data) and LLM internal representations (from activation analysis).

Importantly, we show that biases in LLMs arise from the same network structural properties that produce human biases, suggesting that the dual-process account has computational validity beyond mere metaphor. The work provides a principled framework for understanding when and why memory-based AI systems will exhibit problematic biases, with implications for both AI safety and cognitive science.
