# BrainMem: 受大脑启发的 Agent 进化记忆系统

> 免训练的层次化记忆框架，让 Agent 像人一样从经验中学习——工作记忆 + 情景记忆 + 语义记忆

## 核心问题

基于 LLM 的具身任务规划器存在两个根本性缺陷：

1. **短期记忆缺失**: Agent 在执行多步任务时丢失上下文。典型案例：清理海绵任务中，Agent 反复开关水龙头但不把海绵放到水下——因为它"忘记"了自己已经打开了水龙头
2. **长期经验缺失**: Agent 无法跨任务积累经验。典型案例：摆放餐具任务中，Agent 不知道杯子和刀叉的组合关系，因为它从未从过去任务中学到这种物体组合知识

现有 LLM 规划器本质上是**无状态的反应式系统**——每次推理都从零开始，没有持久化的经验积累。

## 方法/架构

BrainMem 提出受人类认知科学启发的三层记忆架构，完全免训练，可即插即用到任何多模态 LLM：

### 1. 工作记忆（Working Memory）
- **时间尺度**: 单任务执行期间
- **功能**: 缓冲最近的动作、反馈和 Agent 状态
- **结构**: 滑动窗口，每个动作后更新
- **类比**: 人的"短期记忆"——记住当前正在做什么

### 2. 情景记忆（Episodic Memory）
- **时间尺度**: 跨任务
- **功能**: 存储任务轨迹的结构化知识图谱
- **结构**: 图结构，节点为状态/动作，边为因果/时序关系
- **演化**: 执行过程中逐步积累轨迹结构
- **类比**: 人的"情景记忆"——记住上次做类似任务的经历

### 3. 语义记忆（Semantic Memory）
- **时间尺度**: 长期
- **功能**: 从情景记忆中蒸馏出符号化的行为指南
- **结构**: 抽象化的规则/策略集合
- **演化**: 任务完成后，情景经验自动总结为语义指南
- **类比**: 人的"语义记忆"——知道"怎么做事"的一般性知识

### 记忆整合机制
- **执行期间**: 工作记忆随每一步动作更新，情景图谱逐步积累轨迹结构
- **任务完成后**: 情景经验通过自动总结整合为语义指南，无需梯度更新或外部监督
- **规划期间**: BrainMem 检索上下文相关的历史经验来增强决策质量

## 实验结果

在四个具身规划基准上评估：

| 基准 | 任务类型 | 提升幅度 |
|------|---------|---------|
| EB-ALFRED | 家务任务（长程） | 显著提升 |
| EB-Navigation | 导航任务 | 显著提升 |
| EB-Manipulation | 操作任务 | 显著提升 |
| EB-Habitat | 通用具身任务 | 显著提升 |

- **长程任务提升最大**: 需要多步协调和组合推理的任务中，BrainMem 的增益最显著
- **消融实验**: 验证了层次化记忆组织和进化机制的必要性——去掉任一层都导致性能下降
- **跨模型泛化**: 对不同多模态 LLM 均有效，不需要任务特定的微调

## 关键洞察

**记忆是 Agent 成熟的关键缺失环节**: 当前 Agent 研究聚焦于推理能力（CoT、ToT）和工具使用，但忽视了记忆——这恰恰是人类从"新手"变"专家"的核心机制。BrainMem 的三层架构直接对标认知科学的工作/情景/语义记忆理论，提供了可工程化的实现。

**免训练设计的端侧意义**: BrainMem 完全不需要梯度更新——记忆通过规则化的整合和蒸馏机制演化。这意味着它可以直接部署在手机端，不需要云端训练支持。对于端侧 Agent 系统，这是一个关键优势。

**知识图谱 + 符号指南的双层表示**: 不是简单的向量存储，而是结构化的知识图谱（情景）+ 符号化的规则集合（语义）。这种表示更可解释、更可压缩，适合端侧存储约束。

## 为什么重要

对手机端 AIOS Agent 的直接影响：
- **持续学习**: 手机端 Agent 需要从用户的日常交互中学习——哪些操作组合常用、哪些步骤容易出错。BrainMem 的进化记忆机制提供了实现路径
- **跨应用知识迁移**: 工作记忆处理当前应用，情景记忆积累跨应用经验，语义记忆提取通用操作模式——这正是手机端 AIOS 需要的三层知识体系
- **无需云端**: 免训练 + 符号化蒸馏意味着所有记忆操作都可以在端侧完成，不依赖云端微调
- **个性化适配**: 随着使用时间增长，语义记忆会逐步形成用户特定的行为指南——真正的个性化 Agent
