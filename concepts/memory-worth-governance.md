# Memory Worth: Agent 记忆治理的轻量级原语

> 提出 Memory Worth (MW) 信号——每个记忆两个计数器——追踪记忆与成功/失败结果的共现频率，为记忆的过时检测、检索抑制和弃用决策提供理论基础。
> 
> 来源: Baris Simsek, 2026-04

## 核心问题

Agent 记忆系统持续积累经验，但缺乏**操作性的记忆质量治理指标**——决定哪些记忆值得信任、抑制或弃用。现有方法的局限：

- **写入时重要性评分**（如 Generative Agents）：静态分配，永不随结果更新
- **LLM 判断式管理**：依赖外部模型，计算开销大且不稳定
- **结构启发式**：仅考虑时间衰减或检索频率，不考虑实际效果
- **反思式更新**（Reflexion）：在 episode 级别存储反思，而非逐记忆追踪

核心矛盾：**记忆写入时的预测"未来会有用"可能正确，但随时间推移变得错误**。

## 方法架构: Memory Worth (MW)

### 核心信号

每个记忆 m 维护两个标量计数器：
- **success_count(m)**：检索该记忆后任务成功的次数
- **retrieval_count(m)**：该记忆被检索的总次数

**Memory Worth** 定义为：
```
MW(m) = success_count(m) / retrieval_count(m)
```

### 理论保证

**定理**: 在平稳检索机制下（满足最小探索条件），MW 几乎必然收敛到条件成功概率：
```
p⁺(m) = Pr[y_t = +1 | m ∈ M_t]
```
即"检索记忆 m 后任务成功的概率"。这是一个关联性量（非因果），但作为操作信号足够有用。

**重要特性**：
- 仅需两个标量计数器，**计算开销接近零**
- 可以添加到任何已记录检索和结果的架构中
- 不需要 LLM 判断或额外推理

### 应用场景

| 决策 | MW 阈值 | 效果 |
|------|---------|------|
| 检索抑制 | MW < 0.2 | 低价值记忆不再参与检索 |
| 过时检测 | MW 持续下降 | 检测记忆因任务分布变化而失效 |
| 弃用决策 | MW ≈ 0 且检索次数足够 | 安全移除无用记忆 |

## 实验结果

### 实验 1: 合成环境验证
- 20 个独立种子，每个 10,000 episodes
- MW 与真实效用的 Spearman 等级相关系数：**ρ = 0.89 ± 0.02**
- 对比永不更新评估的系统：**ρ = 0.00**

### 实验 2-4: 失效模式分析
| 失效模式 | 影响 | 缓解 |
|----------|------|------|
| 任务难度混淆 | 全局 MW 负相关 (ρ ≈ -0.33) | 按任务难度条件化恢复正信号 (ρ ≈ +0.14 ± 0.07) |
| 检索策略反馈 | 在测试的 softmax 范围内未导致崩溃 | 无需特殊处理 |
| 共检索混淆 | 需要 ~30% 检索多样性 | 增加检索策略随机性 |

### 实验 5: 嵌入检索验证
- 使用 **all-MiniLM-L6-v2** 标准嵌入检索
- 3,000 episodes
- 过时记忆 MW 降至 **0.17**，专家记忆稳定在 **0.77**
- 验证了语义检索系统天然诱导的共检索混淆路径

## 关键洞察

**MW 与现有方法的互补性**：
- **A-MAC (Adaptive Memory Admission Control)** 控制什么进入记忆（写入时评分）
- **Memory Worth** 追踪已存在记忆的实际表现（检索后更新）
- 两者互补：A-MAC 把门，MW 评估在库中的记忆

**为什么关联性比因果性更实用**：
- 严格区分"记忆导致成功"需要反事实推理，计算成本极高
- "检索该记忆时成功概率更高"作为操作信号已经足够
- 在资源受限的边缘设备上，关联性评估的低开销至关重要

**对端侧 Agent 的启示**：
- 移动设备内存有限，不可能无限积累记忆
- MW 提供了一种**无需额外推理开销**的记忆质量评估方式
- 两个计数器的存储成本可以忽略不计

## 为什么重要

Memory Worth 对手机端 AI Agent 的核心价值：

1. **内存效率**：移动设备内存受限，需要主动清理低质量记忆
2. **实时性**：两个计数器的更新是 O(1) 操作，不影响推理延迟
3. **个性化**：随用户使用自动学习哪些记忆对特定用户有价值
4. **隐私**：不需要将记忆内容发送给外部模型评估

这对小米小爱、华为小艺等端侧 Agent 的记忆管理有直接参考价值——如何在有限的设备内存中维护高质量的记忆子集。
