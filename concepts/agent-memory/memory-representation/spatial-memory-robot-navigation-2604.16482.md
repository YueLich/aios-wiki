## 摘要

A Survey of Spatial Memory Representations for Efficient Robot Navigation. This paper surveys spatial memory representations used in robot navigation systems, covering topological maps, metric maps, semantic maps, hybrid representations, and learnable approaches. The survey analyzes how different representations balance efficiency, accuracy, and generalization across various navigation scenarios.

## 核心贡献

1. **空间记忆表示系统综述**：全面覆盖拓扑地图、度量地图、语义地图、混合表示和可学习方法。
2. **效率-准确性-泛化性权衡分析**：分析不同表示在不同导航场景下的权衡。
3. **移动机器人的适用性评估**：评估各表示对移动端/机器人导航的适用性。
4. **未来方向**：识别空间记忆在机器人导航中的研究空白和未来方向。

## 为什么重要

空间记忆是移动机器人和移动端 Agent 的核心能力之一。本综述为研究者和工程师提供了空间记忆表示的全面参考框架，帮助在具体应用中选择合适的表示方法。覆盖从传统几何方法到最新学习方法的完整谱系，对理解移动端空间认知系统设计有重要价值。

## 与移动端/端侧相关性

- 移动端导航应用（AR 导航、机器人吸尘器、智能车载）依赖空间记忆
- 拓扑地图极度紧凑，适合存储受限的移动端
- 语义地图与移动端 POI（兴趣点）数据库自然结合
- 混合表示可能在精度和效率之间提供最佳平衡，适合资源受限的移动设备
