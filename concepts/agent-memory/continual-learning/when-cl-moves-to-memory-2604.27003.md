# When Continual Learning Moves to Memory: A Study of Experience Reuse in LLM Agents

## 论文基本信息

- **arXiv ID**: 2604.27003
- **作者**: Qisheng Hu, Quanyu Long, Wenya Wang
- **提交日期**: 2026-04-29
- **类别**: cs.LG, cs.AI

## 摘要

记忆增强 LLM Agent 为持续学习提供了诱人捷径：不更新模型参数，而是将经验积累在外部记忆中，似乎回避了参数学习的稳定性-可塑性困境。本文证明这一挑战并未消失，而是以记忆层面的形式重新出现。在有限上下文窗口下，新旧经验在检索时相互竞争，将持续学习瓶颈从参数更新重新定位到记忆访问。为研究这一现象，论文引入 (k,v) 框架分解外部记忆的两个基本设计轴：经验如何表示以及如何组织检索。在 ALFWorld 和 BabyAI 的顺序任务实验中发现：抽象程序记忆比详细轨迹更可靠地迁移，负迁移对困难案例影响更大，更细粒度的记忆组织并非普遍有益。

## 核心贡献

1. **(k,v) 框架**：将外部记忆设计分解为经验表示与检索组织两个正交维度。
2. **发现瓶颈转移**：证明持续学习瓶颈从参数更新迁移到记忆访问的新现象。
3. **抽象 > 具体**：实验证明抽象程序记忆比详细轨迹迁移效果更好。
4. **负迁移分析**：困难案例受负迁移影响最大，细粒度组织不总是有益。

## 为什么重要

这是首篇系统研究「记忆增强 CL 是否真正解决了 CL 问题」的论文。结果令人警醒：外部记忆并不能消除持续学习的根本矛盾，只是将战场从参数空间转移到记忆空间。这对依赖 RAG 进行持续学习的 Agent 系统有重要影响。对移动端/端侧的意义：移动端 Agent 如果依赖外部记忆进行持续学习，同样面临检索竞争问题。

## 与移动端/端侧相关性

- 移动端 Agent 的外部记忆（设备端向量库）在上下文窗口满时同样面临新旧经验竞争
- 抽象程序记忆 > 详细轨迹的发现对移动端任务记忆设计有指导意义（存储意图/策略而非完整操作序列）
- 负迁移对困难案例影响最大的发现意味着移动端 corner case 需要更谨慎的记忆策略
