# Human-Inspired Context-Selective Multimodal Memory for Social Robots

## 论文基本信息

- **arXiv ID**: 2604.12081
- **作者**: Hangyeol Kang, Slava Voloshynovskiy, Nadia Magnenat Thalmann
- **提交日期**: 2026-04-13
- **类别**: cs.AI

## 摘要

记忆是社交互动的基础，使人类能够回忆有意义的历史经历并据此调整行为。然而当前大多数社交机器人和具身 Agent 依赖非选择性的纯文本记忆，限制了支持个性化、上下文感知交互的能力。本文从认知神经科学获得灵感，提出面向社交机器人的上下文选择性多模态记忆架构，捕捉并检索文本和视觉情景痕迹，优先处理高情感显著度或场景新颖性时刻。通过将这些记忆与个体用户关联，系统支持社交个性化回忆和更自然、更 grounded 的对话。在社交场景数据集上验证选择性存储机制，Spearman 相关系数达 0.506，超越人类一致性（ρ=0.415），并优于现有图像可记忆性模型。

## 核心贡献

1. **认知神经科学启发**：借鉴人类记忆的选择性机制（情感显著性和场景新颖性优先）。
2. **多模态情景记忆**：同时捕捉文本和视觉记忆，而非纯文本。
3. **个性化关联**：记忆与用户身份关联，支持个性化回忆。
4. **可测量选择机制**：选择性存储决策可量化评估，Spearman 0.506 超越人类基准。

## 为什么重要

首篇将人类记忆的选择性机制（并非所有经历同等重要）形式化并工程化的论文。情感显著性作为记忆优先级指标具有普适性，可应用于任何需要长期记忆的 Agent 系统。对移动端/端侧的意义：移动设备上的情感计算（情感助手、心理健康应用）可直接借鉴此架构。

## 与移动端/端侧相关性

- 移动端情感助手/心理健康 Agent 可利用情感显著性指导记忆存储优先级
- 视觉情景记忆与移动端相册回忆、AR 找物功能直接相关
- 选择性存储减少存储开销，适合端侧资源受限环境
- 多模态记忆为移动端多传感器融合（摄像头+麦克风+IMU）提供了统一框架
