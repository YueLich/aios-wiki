# When to Forget: A Memory Governance Primitive

## 论文基本信息

- **arXiv ID**: 2604.12007
- **作者**: Baris Simsek
- **提交日期**: 2026-04-13
- **类别**: cs.AI

## 摘要

Agent 记忆系统积累经验，但目前缺乏记忆质量治理的原则性操作指标——即如何决定哪些记忆可信、抑制或废弃，因为 Agent 任务分布发生变化。写时重要性评分是静态的；动态管理系统使用 LLM 判断或结构启发而非结果反馈。本文提出 Memory Worth（MW）：一种每个记忆的双计数器信号，跟踪记忆在成功 vs 失败结果中共同出现的频率，提供轻量级、有理论基础的陈旧检测、检索抑制和废弃决策基础。论文证明在稳态检索制度和最小探索条件下，MW 几乎surely收敛于条件成功概率 p+(m)。重要的是，p+(m) 是关联量而非因果量——它衡量的是记忆被检索时任务成功的共现概率，而非因果关系。

## 核心贡献

1. **Memory Worth 指标**：每个记忆双计数器跟踪成功/失败共现频率，提供记忆质量的可量化信号。
2. **理论基础**：证明 MW 在温和条件下收敛于条件成功概率 p+(m)。
3. **陈旧检测 + 检索抑制 + 废弃决策**：三种治理原语基于统一的 MW 信号。
4. **轻量级实现**：无需 LLM 判断或复杂结构启发，仅依赖可观测结果。

## 为什么重要

这是 Agent 记忆系统「治理」方向的开创性工作，提出了第一个可量化的记忆质量指标。现有系统要么依赖写时静态评分，要么依赖推理时 LLM 判断，MW 提供了一种基于结果的动态反馈机制。对移动端/端侧 Agent 的意义：端侧无法运行复杂 LLM 判断，轻量级的双计数器 MW 机制非常适合资源受限环境。

## 与移动端/端侧相关性

- 端侧无法运行大模型进行记忆质量判断，MW 的轻量级计数器机制完美适配
- 隐私敏感场景下 MW 不需要理解记忆内容，只需跟踪使用结果
- 可与移动端通知管理、App 使用习惯记忆等具体场景结合
