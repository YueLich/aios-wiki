# 开源工具 / SDK 与合规资料

1. **ActivityWatch** — ActivityWatch 社区（Erik Bjäreholt 等），2014–2024 (v0.13.2) — 跨平台（Windows/macOS/Linux/Android）开源自动时间追踪器，记录"当前活动应用+窗口标题+浏览器标签+AFK"，提供 REST API 与查询语言 — https://github.com/ActivityWatch/activitywatch — 研究 OS 行为日志采集可直接使用的工具。
2. **ulogme** — Andrej Karpathy，2014 — 早期流行的桌面活动可视化日志工具 — https://github.com/karpathy/ulogme — 被列为 ActivityWatch 对标项目之一。
3. **Privacy in Sensor-Driven Human Data Collection: A Guide for Practitioners** — Arkadiusz Stopczynski、Alex Pentland、David Lazer、Sune Lehmann（MIT/Northeastern）— 2014, arXiv — https://arxiv.org/abs/1403.5299 — 传感器驱动的人行为采集隐私实践指南，可作为合规采集 OS 操作日志的参考框架。
