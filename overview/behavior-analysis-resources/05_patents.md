# 专利清单

按公司分组。所有专利号均来自 Google Patents API 检索结果，链接采用 `patents.google.com/patent/<号>/en` 标准格式。

## E1. Google / Android

1. **Managing applications on a client device** — US-9063811-B2 — Google Inc. — 2015 — https://patents.google.com/patent/US9063811B2/en — 计算每个 app 的"情境效用分数（situational utility score）"做管理/推荐，典型 OS 级上下文感知应用推荐。
2. **Native machine learning service for user adaptation on a mobile platform** — US-8429103-B1 — Google Inc. — 2013 — https://patents.google.com/patent/US8429103B1/en — 移动平台原生 ML 服务做用户自适应，端侧行为学习/个性化基础架构。
3. **Predicting intent of a search for a particular context** — US-10909124-B2 — Google LLC — 2021 — https://patents.google.com/patent/US10909124B2/en — 基于一组计算设备上用户主动操作判定搜索意图，跨设备行为意图预测。

## E2. Microsoft

4. **Enhanced computer experience from activity prediction** — US-11429883-B2 — Microsoft Technology Licensing — 2022 — https://patents.google.com/patent/US11429883B2/en — 从一组计算设备的信号数据得出活动模式推断意图/预测下一步，Windows Timeline/活动历史核心专利。
5. **Prediction-based action-recommendations in a cloud system** — US-11423095-B2 — Microsoft Technology Licensing — 2022 — https://patents.google.com/patent/US11423095B2/en — 利用应用使用数据预测并推荐操作（保存/协作/上传），应用使用行为→动作推荐。
6. **Recommendations for reducing data consumption based on data usage profiles** — US-9887894-B2 — Microsoft Technology Licensing — 2018 — https://patents.google.com/patent/US9887894B2/en — 按已装应用的数据使用模式对用户画像并给个性化推荐。
7. **Computer speech recognition and semantic understanding from activity patterns** — US-10769189-B2 — Microsoft Technology Licensing — 2020 — https://patents.google.com/patent/US10769189B2/en — 用计算设备信号得出活动模式推断意图，结合 Cortana 语义理解，OS 行为感知+助手推荐。
8. **Predictive pre-launch for applications** — US-9508040-B2 — Microsoft Technology Licensing — 2016 — https://patents.google.com/patent/US9508040B2/en — 基于"应用被激活的评估概率"预先启动，智能预加载/预测缓存代表。
9. **Surfacing underutilized tool features** — US-11714613-B2 — Microsoft Technology Licensing — 2023 — https://patents.google.com/patent/US11714613B2/en — 监测用户与工具交互的低效点后浮现被忽略功能，基于操作行为的功能推荐。

## E3. Apple

10. **App recommendation using crowd-sourced localized app usage data** — US-10474727-B2 — Apple Inc. — 2012（优先权）— https://patents.google.com/patent/US10474727B2/en — 利用本地化应用使用数据做应用推荐，直接对应"应用操作记录→推荐"。
11. **Feature determination for machine learning to suggest applications/recipients** — US-11507863-B2 — Apple Inc. — 2020（优先权）— https://patents.google.com/patent/US11507863B2/en — 用 ML 基于特征建议应用/收件人，Siri 建议类应用推荐。
12. **Systems and methods for proactively identifying and surfacing relevant content** — EP-3779685-B1 — Apple Inc. — 2015（优先权）— https://patents.google.com/patent/EP3779685B1/en — 主动识别并呈现与用户上下文相关内容，Siri 上下文感知推荐。
13. **User interfaces for controlling or presenting device usage** — US-12547521-B2 — Apple Inc. — 2018（优先权）— https://patents.google.com/patent/US12547521B2/en — 设备使用监测/呈现（Screen Time 方向）。
14. **Providing user interfaces based on use contexts and managing playback of media** — EP-3966677-B1 — Apple Inc. — 2019（优先权）— https://patents.google.com/patent/EP3966677B1/en — 基于"使用上下文"提供界面，上下文特征工程。
15. **Sharing routine for suggesting applications to share content** — US-11792242-B2 — Apple Inc. — 2019（优先权）— https://patents.google.com/patent/US11792242B2/en — 基于上下文建议用于分享的目标应用，操作行为→应用推荐。

## E4. Samsung

16. **Effective user modeling with time-aware based binary hashing** — US-11615302-B2 — Samsung Electronics — 2023 — https://patents.google.com/patent/US11615302B2/en — 采集序列化用户行为数据抽取短/长期特征做用户建模，时序行为预测模型。
17. **Recommending applications** — US-9942358-B2 — Samsung Electronics — 2018 — https://patents.google.com/patent/US9942358B2/en — 接收应用通知并基于通知数据推荐应用，负一屏/智慧助手类应用推荐。
18. **Method for automating actions for an electronic device** — US-11972327-B2 — Samsung Electronics — 2024 — https://patents.google.com/patent/US11972327B2/en — 基于域信息检索关联活动模式生成候选动作规则，行为模式→自动化推荐。
19. **Smart alarm** — US-RE48278-E1 — Samsung Electronics — 2020 — https://patents.google.com/patent/USRE48278E1/en — 用电子设备发现个人信息并据此提供个性化内容，设备侧行为画像→个性化推荐。

## E5. Huawei

20. **System and method for multi-task lifelong learning on personal device with recommendations** — US-20230052903-A1 — Huawei Technologies — 2023（公开）— https://patents.google.com/patent/US20230052903A1/en — 采集用户行为数据分组打标训练 ML 模型做推荐，端侧终身学习行为推荐。
21. **System and method for user-behavior based content recommendations** — AU-2021240234-B2 — Huawei Technologies — 2023 — https://patents.google.com/patent/AU2021240234B2/en — 基于用户行为预测其最有意义的多媒体内容，用户行为分析→推荐。
22. **Voice interaction method and apparatus** — US-11922935-B2 — Huawei Technologies — 2024 — https://patents.google.com/patent/US11922935B2/en — 基于可触发语音交互的目标事件预测用户语音交互意图的服务类型，行为事件→意图预测。

## E6. 其他（智能预加载 / 跨设备）

23. **Transparent Pre-Loading of User Applications** — US-20210329089-A1 — Tensera Networks Ltd. — 2021 — https://patents.google.com/patent/US20210329089A1/en — OS 维护跟踪用户应用活动数据结构据此透明预加载应用，predictive cache/prefetch 方向。
