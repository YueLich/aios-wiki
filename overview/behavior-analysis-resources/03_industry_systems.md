# 工业系统论文 / 工程资料

1. **EdgeRec: Recommender System on Edge in Mobile Taobao** — Yu Gong 等（阿里巴巴淘宝）— 2020, CIKM — https://arxiv.org/abs/2005.08416 — 首个明确"端侧实时用户感知+实时反馈"的工业推荐系统，用异构用户行为序列建模，淘宝首页上线 GMV +11%。
2. **Fortress: Stabilizing Search Recommendations via Temporal Data Augmentation and Feature Pruning** — Milind Pandurang Jagre、Puja Das、Chris Alvino 等（Apple）— 2026, IEEE SoutheastCon — https://machinelearning.apple.com/research/fortress-stabilizing-search-recommendations — Apple 官方关于工业级行为日志推荐系统的时序数据稳定性治理案例。
3. **Asymmetric Diffusion Recommendation Model (AsymDiffRec)** — Yongchun Zhu、Zuotao Liu 等（字节跳动 / 抖音音乐）— 2025, CIKM — https://arxiv.org/abs/2508.12706 — 抖音音乐 App 上线 A/B 测试，扩散模型在用户行为样本缺失下提升留存。
4. **ZEL: Net-Zero-Energy Lifelogging System using Heterogeneous Energy Harvesters** — Mitsuru Arita、Yutaka Arakawa 等（NTT/Kyushu U.）— 2022, IEEE PerCom — https://arxiv.org/abs/2202.00247 — 企业员工低功耗穿戴式行为/位置采集系统，工业级日志采集工程实现。
